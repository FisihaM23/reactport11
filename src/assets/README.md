# Add Your Images Here

Please add the following images to this folder (`src/assets/`):

## Required Images:

1. **muler.jpg** - Your profile photo
   - Recommended size: 350x350px (square)
   - Will be displayed as a circle on the home page
   - Format: JPG

2. **system.jpg** - ATM Transaction System project screenshot
   - Recommended size: 600x400px (landscape)
   - Format: JPG

3. **library.png** - Library Management System project screenshot
   - Recommended size: 600x400px (landscape)
   - Format: PNG

## How to Add Images:

1. Copy your images to this folder: `src/assets/`
2. Make sure the file names match exactly:
   - muler.jpg
   - system.jpg
   - library.png
3. Restart the development server if it's running

## Image Tips:

- Use high-quality images for better appearance
- Profile photo should be well-lit and professional
- Project screenshots should show the main interface
- Keep file sizes reasonable (under 1MB each)

Once you add the images, they will automatically appear in your portfolio!
